# Definition of Done — AdForge v1

AdForge v1 is **DONE** only when all of the following are demonstrated:

1. A campaign is created through the desktop web UI.
2. Warranty Vault is selected.
3. Product Truth is validated and snapshotted.
4. A simple campaign brief is entered.
5. Strategy, script, storyboard and asset plan are autonomously produced.
6. Required AI media is generated through the configured provider OR a real handoff package is proven and successfully re-imported.
7. Authentic Warranty Vault UI footage is captured through emulator OR the emulator handoff is proven and successfully re-imported.
8. Voice/music/SFX are produced without requiring user-supplied ordinary audio.
9. A machine-readable edit plan is produced.
10. FFmpeg renders a valid draft.
11. QC runs and records results.
12. Targeted repair works for at least one intentionally induced/reproducible failure.
13. Final 9:16 MP4 is rendered and playable.
14. Production ledger, asset manifest, Product Truth snapshot and render spec exist.
15. Campaign survives a controlled application restart and resumes without starting over.
16. One-active-campaign enforcement works.
17. No unsupported Warranty Vault claim appears in the accepted ad.
18. No manual external video editing is used.
19. Automated test suite and release verification pass.
20. Documentation matches the implemented system.

Until these pass, the release verdict is **NOT READY**.
