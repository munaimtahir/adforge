# Campaign Workflow

1. Create campaign and freeze brief.
2. Resolve product and create Product Truth snapshot.
3. Develop strategy.
4. Produce timed script and screen text.
5. Produce storyboard and continuity sheet.
6. Build asset plan:
   - REUSE
   - GENERATE_IMAGE
   - GENERATE_VIDEO
   - CAPTURE_APP
   - GENERATE_AUDIO
   - RENDER_GRAPHIC
7. Generate/capture assets.
8. Produce audio.
9. Build machine-readable edit specification.
10. Render draft.
11. Run lenient v1 QC.
12. Repair only failed/weak elements where useful and within budget.
13. Render final.
14. Derive required formats/variants.
15. Export MP4 + manifest + ledger + truth snapshot + subtitles where applicable.
16. Mark COMPLETE only after acceptance gates pass.
