# AI Routing Policy

## Default tendencies
Claude/Claude Code:
- creative strategy
- script/story
- semantic review
- claim reasoning
- prompt refinement

Codex:
- implementation
- shell/tool execution
- Android/ADB
- FFmpeg
- debugging
- test repair
- infrastructure

## But
These are preferences, not locks. The router may assign either model based on observed capability and availability.

## Subscription-first policy
1. Authenticated subscription CLI/tool
2. Supported browser workflow
3. External handoff
4. Optional API only if separately configured/enabled

## No hidden dependence
The system must remain usable if either Claude or Codex is temporarily unavailable.
