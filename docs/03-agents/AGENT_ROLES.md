# Logical Agent Roles

These are logical roles, not necessarily separate models.

- Production Director — interprets brief and coordinates creative intent.
- Creative Strategist — hook, audience, positioning, narrative.
- Script Agent — narration, on-screen copy, timing.
- Storyboard Agent — scenes, duration, framing, continuity.
- Asset Planner — make/reuse/capture decisions and dependencies.
- Generation Prompt Agent — provider-specific prompts/references.
- Video Generation Worker — Flow/Veo execution.
- Android Capture Worker — emulator/app capture.
- Audio Director — voice/music/SFX plan.
- Edit Director — edit decision list and render spec.
- Render Worker — deterministic FFmpeg execution.
- Visual QC — technical/visual defects.
- Story QC — coherence, pacing, hook, CTA.
- Product Truth QC — claim/evidence enforcement.
- Recovery Agent — infrastructure/provider diagnosis.

## Separation of concerns
The Production Orchestrator is software. The Production Director is an AI role. Never merge the two concepts.
