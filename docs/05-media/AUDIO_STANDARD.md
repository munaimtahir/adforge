# Audio Standard

AdForge owns ordinary audio production.

## Voice
- TTS / generated voice
- authorized voice cloning
- language/accent/tone selected to fit campaign
- voice provenance recorded

## Music
- AI-generated or properly licensed royalty-free source
- provenance/license reference recorded where available
- no expectation that user supplies music

## SFX
Use only when useful for clarity, rhythm, realism, or impact.

## Mix
- intelligible narration
- music ducked under speech
- no clipping
- consistent loudness
- final technical QC via ffmpeg/ffprobe where practical
