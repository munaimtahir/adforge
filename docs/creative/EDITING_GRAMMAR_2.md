# Editing Grammar 2.0

`EditPlan2` and `EditClip2` define shot identity, source asset, trim, target duration, composition, transition, text layers, audio behavior, z-index, and safe area. Editing patterns include HOOK_CUT, PRODUCT_REVEAL, FEATURE_PROOF, BENEFIT_CUTAWAY, PRODUCT_CONFIRMATION, and CTA_HOLD. Renderers should map these enums to deterministic primitives.
