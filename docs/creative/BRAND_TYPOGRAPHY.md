# Brand Typography

`TypographyInstruction` defines HEADLINE, BENEFIT, CAPTION, CTA, BRAND_LOCKUP, and DISCLAIMER roles with font, weight, size, line spacing, alignment, safe zone, contrast, entrance/hold/exit, and character limits. The current renderer continues using its legal deterministic DejaVu fallback; Product Truth brand overrides can populate CQ2 instructions without committing proprietary font files.
