# v1 Scope and Non-Goals

## In scope
- Single-user web control plane
- Persistent campaign state machine
- Product Truth ingestion/validation
- Claude Code and Codex CLI adapters
- Flow/Veo browser adapter plus generation handoff
- Android APK ingestion
- One emulator profile plus emulator handoff
- Fictional demo data
- AI voice, authorized voice cloning path, music/SFX acquisition/generation
- FFmpeg editing/rendering
- 9:16 / 16:9 / 1:1 outputs
- 6/10/15/20/30-second variants
- Lenient automated QC and targeted repair
- Local storage
- Production ledger, manifests, provenance
- Pause/resume and recovery
- Warranty Vault acceptance campaign

## Explicit non-goals for v1
- Multi-user/multi-tenant SaaS
- Cloud/object storage requirement
- Multiple concurrent campaigns
- Multiple production VMs
- Multiple emulator device matrix
- Direct Meta/Google Ads publishing
- Automated ad spend
- Performance-feedback optimization
- Mandatory paid APIs
- Unsupervised material modification of AdForge's own production code
