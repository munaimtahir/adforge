# Test Contract

Tests must cover, at minimum:
- Product Truth validation and immutability
- campaign state transitions
- retry/pause/resume
- one-active-campaign rule
- restart recovery
- provider contracts
- handoff export/import
- APK safe ingestion/checksum
- asset manifest and ledger
- edit spec validation
- FFmpeg fixture rendering
- QC blockers and lenient advisories
- path traversal / command injection defenses
- secret redaction
